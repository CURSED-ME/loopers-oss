## Critical Facts (Read Before Writing Any Code)

- **Binary path**: `./cmd/loopers` (not `./cmd/server`)
- **Docker image**: `ghcr.io/cursed-me/loopers:latest`
- **Redis env var**: `REDIS_ADDR` (not `REDIS_ADDRESS`)
- **Local dev flag**: `SERVER_INSECURE_DEV=true` — required to run without TLS
- **Proxy key format**: `lp-xxx` — always starts with `lp-`
- **Policy package**: all `.rego` files must use `package loopers.policy`
- **Fail-closed**: if Redis is down, all requests are blocked (no pass-through)

## Quick Setup (Native)

```bash
loopers init                          # generates loopers.yaml + docker-compose.yml
docker-compose up -d redis            # start Redis only
SERVER_INSECURE_DEV=true loopers serve   # start proxy (macOS/Linux)
# Windows: $env:SERVER_INSECURE_DEV="true"; loopers serve

# In a new terminal:
loopers keys create --name mykey --provider openai
loopers budget set <KEY_HASH> --daily 10.00
```

## Architectural Constraints

- Zero-storage: never persist API keys or payload bodies to disk
- Fail-closed: Redis unavailability must block all requests
- Budget checks use Redis Lua scripts (atomic, prevents TOCTOU races)
- OPA policy blocks on MCP tool calls return HTTP 200 with JSON-RPC error code `-32001` (enables LLM self-correction)
